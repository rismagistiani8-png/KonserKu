# 🎟️ KonserKu

Aplikasi mobile pemesanan tiket konser berbasis **React Native (Expo)**.

## Fitur
- Beranda: daftar konser populer dan trending
- Detail Konser: guest star, lokasi, deskripsi, harga tiket
- Pemesanan: pilih kategori, atur jumlah, total harga otomatis
- Konfirmasi: e-ticket digital dengan kode booking

## Teknologi
- React Native + Expo
- React Navigation (Stack Navigator)
- Hooks: useState, useEffect

## Cara Menjalankan
```bash
npm install
npx expo start
```
Scan QR code dengan aplikasi **Expo Go**.
